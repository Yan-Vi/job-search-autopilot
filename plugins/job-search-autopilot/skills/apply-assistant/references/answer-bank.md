# Recruiter answer bank

Answer recruiter questions from the person's own material in `Data/` in this order: Legend `Standard answers`, Profile, earlier answers saved in `Cover Letters/` docs. Never invent.

## Common questions and where the answer comes from

| Question type | Source | Shape |
|---------------|--------|-------|
| English or other language level | Legend standard answers | Level plus test score if any, one sentence on daily use |
| Years of experience with X | Profile key facts and experience dates | Exact years, one example |
| Do you have experience with tool X | Profile skills and bullets | Yes plus one concrete use, or honest gap |
| Domain experience (fintech, gaming, etc.) | Profile domains, Legend gaps | Direct experience, or closest related experience stated honestly |
| Salary expectation | Settings `salary_expectation`, then Legend standard answers | Exact figure and format (gross, B2B). If the two disagree or both are missing, stop and ask; never guess |
| Notice period or availability | Legend standard answers | One sentence |
| Relocation, office, time zone overlap | Legend preferences | One sentence |
| Number of tests, team size, scale | Profile or Legend only | Real numbers only, else describe qualitatively |
| Why this company | Vacancy text plus Profile fit | Two sentences, specific to the product |

## Rules

- 2 to 4 sentences unless the question needs more.
- Answer in the language of the question.
- Answer numbered questions in the same order.
- When a numeric form field changes value after filling (some boards autofill from the profile), re-read it before submit and report any change.
- When an answer is missing from all sources, mark the vacancy as needing review and ask the person. Save their answer into Legend `Standard answers` for next time, after asking.
