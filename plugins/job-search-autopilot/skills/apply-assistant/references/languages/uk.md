# Language preset: Ukrainian (uk)

Apply only when Writing Style has no Ukrainian rules of its own.

## Openings and closings

- Default opening: `Доброго дня! Зацікавила вакансія, маю релевантний досвід з ...`
- Closing: `Буду радий обговорити детальніше` (or `обговорити проєкт`). Match grammatical gender to the person (`рада` for female). No period at the end of a short form letter.

## Translate process terms, keep tool names

Write activities and processes in Ukrainian. Keep tools, frameworks and acronyms in English (Postman, Jira, Playwright, SQL, CI/CD).

| Avoid in Ukrainian text | Use |
|-------------------------|-----|
| testing | тестування |
| manual testing | ручне тестування |
| test automation | автоматизація тестування |
| regression testing | регресійне тестування |
| checks, API checks | перевірки, API-перевірки |
| release risk analysis | аналіз ризиків релізу |
| integration flows | інтеграційні сценарії |
| payments | платежі |

## Do not mix procedures and tools

- Procedures go with `досвід`: `досвід ручного та регресійного тестування`.
- Tools go separately: `працював з Postman, SQL і Jira`.
- Bad: `досвід з ручного тестування, Postman, SQL`.

## Recruiter answers

Answer in Ukrainian when the form or thread is in Ukrainian.
