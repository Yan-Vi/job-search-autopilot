# Cover letter HTML template

```html
<html><body style="font-family:Arial;font-size:10.5pt">
<p style="margin:0"><b>{Name}</b></p>
<p style="margin:0">{Title}</p>
<p style="margin:0;font-size:9pt">{Location} · {Email} · {Phone} · {LinkedIn}</p>
<p>{Date}</p>
<p>{Greeting, e.g. "Dear {Company} team,"}</p>
<p>{Opening: role and why it fits}</p>
<p>{Evidence: 2 to 3 real examples from Profile and Legend matched to vacancy requirements}</p>
<p>{Call to action}</p>
<p>{Closing},<br>{Name}</p>
</body></html>
```

Follow the Writing Style doc for tone, language and banned words. Maximum 3 paragraphs in the body.
